## কেন ‘কাগজ’ তৈরি করা হয়েছে?

বাংলাদেশে একটি গোছানো চাকরির সিভি কিংবা পারিবারিক বিবাহের বায়োডাটা বানাতে গেলে সাধারণত দুটি সমস্যার মুখে পড়তে হয়:

১. **কম্পিউটার কম্পোজের দোকান** সাধারণ MS Word ফরম্যাটিংয়ের জন্য ১০০ থেকে ৩০০ টাকা নেয়, সামান্য পরিবর্তনের জন্য আবার টাকা দিতে হয়, এবং আপনার ফোন নম্বর, বাসার ঠিকানা, এনআইডি, পরিবারের তথ্য ও ব্যক্তিগত ছবি অচেনা মানুষের কম্পিউটারে থেকে যায়।
২. **বিদেশি অনলাইন সিভি বিল্ডারগুলো** বাংলাদেশের শিক্ষা ব্যবস্থা (SSC / HSC / Honours / Masters ও GPA/CGPA স্কেল), বাংলাদেশি সিভির ব্যক্তিগত তথ্য বা বিবাহের বায়োডাটার সংস্কৃতি (*দেশের বাড়ি*, অভিভাবকের যোগাযোগ, ধর্মীয় সূচনা) বোঝে না — আর পরিষ্কার PDF ডাউনলোড করতে গেলে একাউন্ট, টাকা বা ওয়াটারমার্কের শর্ত দেয়।

**কাগজ** এই দুটি সমস্যারই সমাধান করে। সহজ স্কেচবুকের মতো বন্ধুত্বপূর্ণ ইন্টারফেসে ধাপে ধাপে তথ্য বসিয়ে কয়েক মিনিটেই তৈরি করুন পরিচ্ছন্ন, মার্জিত ও প্রিন্ট-রেডি A4 PDF — সম্পূর্ণ আপনার নিজের ব্রাউজারে, **কোনো সার্ভার ছাড়া** এবং **আজীবন বিনামূল্যে**।

## মূল বৈশিষ্ট্যসমূহ

### বাংলাদেশের উপযোগী দুটি আলাদা মোড
- **বাংলাদেশি সিভি বিল্ডার (চাকরি ও একাডেমিক)** — দেশের ব্যাংক, কর্পোরেট প্রতিষ্ঠান, এনজিও, সরকারি চাকরি ও বিশ্ববিদ্যালয়ের চাহিদা অনুযায়ী সাজানো। এতে রয়েছে SSC/HSC/Honours/Masters/Diploma-এর বোর্ড ও GPA/CGPA টেবিল, ক্যারিয়ার অবজেক্টিভ টেমপ্লেট, কাজের অভিজ্ঞতা ও ইন্টার্নশিপ, দক্ষতা ও ভাষা, প্রজেক্ট, প্রশিক্ষণ ও সার্টিফিকেশন, ঐচ্ছিক ব্যক্তিগত তথ্য ব্লক, রেফারেন্স, কাস্টম সেকশন এবং ঘোষণা ও স্বাক্ষর।
- **বিবাহের বায়োডাটা বিল্ডার (বিয়ে / বিবাহ)** — বাংলাদেশের পরিবারগুলো যেভাবে কাগজে প্রিন্ট করে বা হোয়াটসঅ্যাপে PDF পাঠায়, ঠিক সেভাবেই তৈরি। এতে আছে ধর্মীয় বা নিরপেক্ষ সূচনা (বিসমিল্লাহির রাহমানির রাহিম, ওঁ / শ্রী শ্রী দুর্গা সহায়, খ্রিস্টান ও বৌদ্ধ আশীর্বাদ, নিরপেক্ষ বা কাস্টম), এক ক্লিকে ছবি লুকানো/দেখানো, জন্মতারিখ থেকে স্বয়ংক্রিয় বয়স হিসাব, শিক্ষা ও পেশা, পারিবারিক পরিচিতি ও ভাই-বোন, বর্তমান ঠিকানা ও *দেশের বাড়ি* (গ্রাম/উপজেলা/জেলা), নিজের কথা, জীবনসঙ্গীর প্রত্যাশা এবং অভিভাবকের হোয়াটসঅ্যাপ/ফোন নম্বর।

### ৫৯টি প্রিন্ট-রেডি A4 টেমপ্লেট
- **২২টি বাংলাদেশি সিভি টেমপ্লেট** — ফর্মাল, কর্পোরেট ও ব্যাংক, সাইডবার, টেক ও আধুনিক এবং কমপ্যাক্ট ডিজাইন।
- **৩৭টি বিবাহের বায়োডাটা টেমপ্লেট** — রাজকীয় (Royal), ফ্লোরাল, ইসলামিক, হিন্দু / সনাতন, খ্রিস্টান ও বৌদ্ধ, আধুনিক এবং হোয়াটসঅ্যাপ-বান্ধব ডিজাইন।
- **১ পৃষ্ঠা ও ২ পৃষ্ঠার ফরম্যাট** — সংক্ষিপ্ত ১ পৃষ্ঠা বা বিস্তারিত ২ পৃষ্ঠার জন্য আলাদা প্রশ্নাবলি ও স্মার্ট লেআউট সমন্বয়।

### স্মার্ট জিরো-কাট A4 PDF ইঞ্জিন
- **এক ক্লিকেই সরাসরি A4 PDF ডাউনলোড** — কোনো ওয়াটারমার্ক বা সাইন-আপ নেই; মোবাইল ও ল্যাপটপ উভয় থেকেই নির্বিঘ্নে কাজ করে।
- **কোনো সেকশন মাঝখান থেকে কাটবে না** — স্মার্ট পেজিনেশন স্বয়ংক্রিয়ভাবে প্রতিটি সেকশন ও টেবিলকে অক্ষত রেখে পরের পৃষ্ঠায় সাজায় এবং প্রতিটি পৃষ্ঠায় বর্ডার ফ্রেম সুন্দরভাবে বজায় রাখে।
- **খালি ঘর স্বয়ংক্রিয়ভাবে বাদ** — যে ঘরগুলো আপনি পূরণ করবেন না, সেগুলো চূড়ান্ত PDF থেকে নিজেই উধাও হয়ে যাবে; কোনো বিরক্তিকর খালি সারি বা `N/A` থাকবে না।

### বিল্ট-ইন অন-ডিভাইস ফটো এডিটর
- ছবি আপলোড করলেই ডকুমেন্টে বসানোর আগে একটি সম্পূর্ণ ফটো এডিটর খুলবে (এবং পরে যেকোনো সময় **ক্রপ / এডিট** বাটনে ক্লিক করে আবার সম্পাদনা করা যাবে)।
- ড্র্যাগ করে পজিশন ঠিক করা, জুম, ৯০° ঘোরানো, সূক্ষ্মভাবে সোজা করা, মিরর ফ্লিপ, **পাসপোর্ট (৪:৫)**, **পোর্ট্রেট (৩:৪)**, **বর্গ (১:১)** বা **ফ্রি কাট** হ্যান্ডেল, **মুখ ও কাঁধের আউটলাইন গাইড**, পাসপোর্ট/গোলাকার/বৃত্তাকার ফ্রেম, স্টুডিও আলো ও টোন প্রিসেট এবং ডকুমেন্টের হেডারে ছবিটি কেমন দেখাবে তার লাইভ প্রিভিউ।

### দ্বিভাষিক, মোবাইল-বান্ধব ও সম্পূর্ণ কাস্টমাইজেবল
- **সম্পূর্ণ বাংলা ও ইংরেজি** সমর্থন — ইন্টারফেস, ডকুমেন্টের শিরোনাম, নমুনা তথ্য এবং বাংলা সংখ্যা।
- **লাইভ কাস্টমাইজেশন** — রঙের থিম ও কাস্টম কালার, ফন্ট স্টাইল (অটো/স্যান্স/সেরিফ), লেখার আকার, স্পেসিং, ছবির আকার ও ফ্রেম, সেকশনের ক্রম বদলানো, সেকশন লুকানো এবং নতুন কাস্টম সেকশন যোগ করা।
- **যেকোনো স্ক্রিনে নিখুঁত** — ছোট স্মার্টফোন (৩২০ পিক্সেল) থেকে ট্যাবলেট, ল্যাপটপ ও বড় মনিটর পর্যন্ত সব স্ক্রিনে স্বাচ্ছন্দ্যে ব্যবহারযোগ্য।

## শূন্য-সার্ভার প্রাইভেসি

‘কাগজ’-এর মূল নীতি হলো — **আপনার ও আপনার পরিবারের ব্যক্তিগত তথ্য কখনোই আপনার ডিভাইসের বাইরে যাবে না**:

- **কোনো সার্ভার নেই, ডাটাবেস নেই, লগইন নেই, কোনো ট্র্যাকার নেই।**
- আপনার খসড়া তথ্য কেবল আপনার নিজের ব্রাউজারের `localStorage`-এ সংরক্ষিত থাকে।
- **প্রাইভেট ব্যাকআপ (`.json`)** ডাউনলোড করে নিজের ফোনে বা কম্পিউটারে রেখে পরে আবার রিস্টোর করতে পারবেন।
- **এক ক্লিকে ‘সব মুছুন’ (Clear Everything)** — পরিবারের শেয়ার করা কম্পিউটার বা সাইবার ক্যাফেতে ব্যবহার শেষে এক ক্লিকে সব তথ্য ও ছবি চিরতরে মুছে ফেলুন।

বিস্তারিত জানতে দেখুন [SECURITY.md](./SECURITY.md)।

## প্রযুক্তি (Tech Stack)

- **ফ্রন্টএন্ড:** React 19 + TypeScript
- **বিল্ড টুল:** Vite 8
- **স্টাইলিং:** Tailwind CSS v4
- **আইকন:** Lucide React
- **PDF এক্সপোর্ট:** `html-to-image` + `jsPDF` (সম্পূর্ণ ক্লায়েন্ট-সাইড)
- **ফটো এডিটর:** নেটিভ HTML5 Canvas API
- **ফন্ট:** Hind Siliguri, Noto Serif Bengali, Cormorant Garamond, Patrick Hand

## লোকাল কম্পিউটারে চালানোর নিয়ম

‘কাগজ’ চালাতে **কোনো API Key বা সার্ভার সেটআপের প্রয়োজন নেই**।

### যা লাগবে
- [Node.js](https://nodejs.org/) (সংস্করণ ২০ বা তার বেশি)

### ইনস্টল ও রান করুন

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/aetheioai/Kagoj.git
cd Kagoj

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. ডেভেলপমেন্ট সার্ভার চালু করুন (http://localhost:3000)
npm run dev
```

### বিল্ড ও টাইপ চেক

```bash
# TypeScript টাইপ যাচাই
npm run lint

# প্রোডাকশন বিল্ড তৈরি (dist/ ফোল্ডারে)
npm run build

# প্রোডাকশন বিল্ড প্রিভিউ
npm run preview
```

## GitHub Pages-এ ডিপ্লয় করার নিয়ম

এই রিপোজিটরিতে ইতিমধ্যেই GitHub Pages-এর জন্য `base: './'`, `public/.nojekyll` এবং স্বয়ংক্রিয় GitHub Actions ওয়ার্কফ্লো (`.github/workflows/deploy.yml`) যুক্ত করা আছে।

১. GitHub-এ আপনার রিপোজিটরির **Settings → Pages**-এ যান।
২. **Build and deployment → Source** থেকে **GitHub Actions** নির্বাচন করুন।
৩. `main` ব্রাঞ্চে কোড পুশ করলেই স্বয়ংক্রিয়ভাবে বিল্ড হয়ে আপনার সাইট লাইভ হয়ে যাবে:
   `https://<username>.github.io/Kagoj/`
