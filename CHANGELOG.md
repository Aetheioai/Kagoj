# Changelog (পরিবর্তনসমূহের তালিকা)

All notable changes to **Kagoj** are documented in this file.

## [1.0.0] - 2026-11-26

### Added (নতুন সংযোজন)
- **Guided 3-Stage Flow**: Purpose Selection -> Template Gallery -> Step-by-Step Editor, Live A4 Preview & Direct PDF Export.
- **59 Print-Ready A4 Templates**:
  - 22 Bangladeshi CV templates (Formal, Corporate & Bank, Sidebar, Tech, Compact).
  - 37 Bangladeshi Marriage Biodata templates (Royal, Floral, Islamic, Hindu/Sanatan, Christian & Buddhist, Modern, WhatsApp-friendly).
- **1-Page & 2-Page Formats**: Dedicated tailored questions and smart layout compression for 1-page documents, plus full multi-page zero-cut pagination for 2-page documents.
- **On-Device Photo Studio Editor**: Automatic crop/cut modal on photo upload with drag/pinch pan, Passport/Portrait/Square/Free Cut handles, head-and-shoulders outline guide, rotate/straighten/flip, studio lighting presets, and live document header preview.
- **Full Bilingual Support (English & বাংলা)**: Complete UI, document headings, sample data, and Bangla digit formatting.
- **Zero-Server Privacy Suite**: Local browser persistence, `.json` private backup/restore, and one-click **Clear Everything** wipe.
- **Full Open-Source & GitHub Pages Support**: Relative Vite base path (`./`), automated GitHub Actions deployment workflow (`https://aetheioai.github.io/Kagoj/`), CI workflow, bilingual README, Contributing, Code of Conduct, Security policy, and Issue/PR templates.
